# 유형테스트 웹사이트
---

천재IT교육센터에서 제공되는 **기획자 유형 알아보기** 테스트 웹페이지입니다.
모든 웹페이지는 정적 호스팅을 가정하여 제작했습니다.

## 호스팅 예시
---

Python을 이용한 테스트 환경 호스팅
`python -m http.server 8000`
